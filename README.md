# Digital-presentation_Using-CV
This video demonstrates my **Computer Vision Digital Presentation** project, where presentation slides are controlled using real-time hand gestures. Built with **Python, OpenCV, and MediaPipe**, the project enables touch-free slide navigation and showcases practical applications of AI, Computer Vision, and gesture recognition.
# 🎯 AI Virtual Presentation Controller using Computer Vision

An AI-powered presentation system that allows users to control PowerPoint slides using **real-time hand gestures**. The application uses **Computer Vision** and **MediaPipe Hand Tracking** to recognize gestures through a webcam, enabling touch-free and interactive presentations.

# ⚙️ How It Works

1. The webcam captures live video.
2. MediaPipe detects and tracks hand landmarks.
3. Specific hand gestures are recognized.
4. Each gesture is mapped to a presentation command.
5. Slides are controlled without touching the keyboard or mouse.

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/Ayush1257m/Computer-Vision-Digital-Presentation.git
```

Move into the project directory

```bash
cd Computer-Vision-Digital-Presentation
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python Presentation.py
```
